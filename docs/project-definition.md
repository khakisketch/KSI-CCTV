# KSI-CCTV 프로젝트 정의

## 제품 비전

KSI-CCTV는 **카메라마다 감지 목적을 다르게 설정하고, 기본 제공 모델과 고객 업로드 모델을 조합해 사용할 수 있는 커스터마이징 지능형 CCTV 플랫폼**입니다.

단순 AI CCTV가 아니라, 발주처와 현장 환경에 맞춰 유연하게 구성 가능한 안전 관리 솔루션입니다.

## 문제 정의

기존 CCTV 안전 관리 시스템의 한계:
- 모든 카메라에 동일한 감지 모델을 적용
- 현장 특성에 맞춘 커스터마이징 어려움
- 모델 추가/변경 시 개발자 의존
- 이벤트별 판단 기준이 유연하지 않음

## 해결 방안

1. **카메라별 프로파일**: 각 카메라마다 도메인(건설, 학교, 공장 등)과 감지 목적을 설정
2. **다중 모델 아키텍처**: 여러 ONNX 모델을 동시에 로드하고 조합하여 사용
3. **이벤트 정책 엔진**: 이벤트별로 YOLO 직접 탐지, VLM 분석, 규칙 기반 판단 방식을 유연하게 구성
4. **사용자 모델 확장**: 비개발자도 ONNX 모델을 업로드해 사용할 수 있는 구조

## 목표 사용자

- 건설 현장 안전 관리자
- 학교/병원/공장 등 시설 안전 담당자
- CCTV 통합 관리 운영자
- AI 모델 개발자 (커스텀 모델 제공)

## 핵심 가치

1. **유연성**: 카메라마다 다른 감지 목적 설정 가능
2. **확장성**: 기본 모델 + 사용자 모델 조합 가능
3. **정확성**: YOLO 고속 필터링 + VLM 정밀 분석 조합
4. **안전성**: 개인정보 보호(얼굴 블러), 보안 격리, 감사 로그
5. **사용성**: 비개발자도 설정 UI로 관리 가능

## 현재 상태

- Phase 0: 프로토타입 완료 (단일 YOLO + VLM + 대시보드)
- Phase 1+: 다중 모델/이벤트 정책 기반 플랫폼으로 확장 중
- 설치형 제품화: 헤드리스 엔진(FastAPI) + **Next.js 웹 콘솔**(데스크톱 관제/모바일 뷰어, 다크·라이트) +
  **MediaMTX 영상 게이트웨이**(라이브 HLS) 구축 — 기존 Streamlit 대시보드와 **병존**(점진 이관 진행,
  [implementation-plan](implementation-plan.md) 참조). open-vocab 텍스트 탐지(학습 없이 탐지대상 변경) 지원.
