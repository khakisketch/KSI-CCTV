# P3 정기 LLM 보고 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 일/주 주기로 이벤트·관측·인시던트를 집계해 LLM으로 서술 보고서를 생성하고 웹콘솔에서 열람·다운로드한다. 엔진은 provider 추상화 뒤에 격리하고, 실패 시 빈 보고서·환각 대체를 금지한다.

**Architecture:** provider 추상화(T1) → 집계+저장소(T2) → 스케줄러+데몬 배선(T3) → 콘솔 페이지(T4) → 문서·게이트(T5). 순차 실행, 한 번에 한 writer.

**Tech Stack:** Python 3.12 · pytest(`-B -p no:cacheprovider`) · ruff · FastAPI · Next.js · SQLite

**Spec:** Plan-mode 확정 내용(2026-09-20 chat: 정기 요약·콘솔 열람·엔진 추상화·A안 승인). SSOT 근거: `src/storage/sqlite_events.py`(event_records), `src/storage/sqlite_observations.py`(시간 버킷), `src/incidents/store.py`(IncidentStore), `src/vlm/ollama_provider.py`(Ollama HTTP 계약 선례).

## Global Constraints

- 테스트는 `./.venv/bin/python -B -m pytest tests/ -p no:cacheprovider`로 실행한다.
- LLM 실패(타임아웃·비정상·파싱 실패) 시 보고서 생성 건너뜀 — 빈 보고서·플레이스홀더·환각 대체 금지.
- 외부 네트워크 LLM 호출 금지 — loopback/private Ollama만 (VLM provider의 endpoint 제한 선례 준수).
- 컨텍스트 토큰 상한 준수 — 초과 시 버킷 요약 우선 축소, 원문 절단 금지·축소 규칙 테스트로 고정.
- 한 공유 워크트리당 작성자 1명. 커밋·푸시·배포는 명시적 승인 후에만.
- 한국어로 응답한다. 기술 용어는 원어 유지.
