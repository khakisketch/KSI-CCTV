# P2 Webhook 알림 채널 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** email 단일 채널을 이벤트×채널 매트릭스 + UI 관리 WebhookEndpoint 레지스트리로 확장한다. 기존 outbox(재시도·백오프·dead-letter·멱등) 계약을 재사용하고, 제품 관행(HMAC-SHA256 서명·복수 URL·발신측 필터링)에 맞춘다.

**Architecture:** 모델+발송자(T1) → AlertManager 배선(T2) → API+RBAC+감사(T3) → 프론트(T4) → 문서·계약·게이트(T5). 순차 실행, 한 번에 한 writer.

**Tech Stack:** Python 3.12 · pytest(`-B -p no:cacheprovider`) · ruff · FastAPI · Next.js · HMAC-SHA256 표준 라이브러리

**Spec:** Plan-mode 확정 내용(2026-09-20 chat: webhookonly·UI 관리·채널별 매트릭스·A안 승인, 제품 관행 Research 2026-09-20). SSOT 근거: `src/events/models.py`(NotificationChannel·NotificationAttempt), `src/alerts/outbox.py`(dispatcher·재시도), `src/alerts/alert_manager.py`(email 경로), `config/alert_preferences.yaml`(임계값·per-event).

## Global Constraints

- 테스트는 `./.venv/bin/python -B -m pytest tests/ -p no:cacheprovider`로 실행한다.
- 시크릿은 테스트에 하드코딩 금지(fake 고정값만). 실제 전송 테스트는 loopback mock 서버로만.
- `config/webhooks.yaml`은 0o600, 시크릿은 생성·회전 시 1회만 평문 반환, 이후 마스킹. URL에 자격정보(user:pass@) 금지, scheme은 http/https만.
- 기존 이메일 동작 불변: 임계값·per-event 기본값·outbox 재시도 상수 변경 금지.
- 한 공유 워크트리당 작성자 1명. 커밋·푸시·배포는 명시적 승인 후에만.
- 한국어로 응답한다. 기술 용어는 원어 유지.

**Files:**

- Create: `src/alerts/webhook.py` (발송자 + 서명)
- Create: `tests/test_webhooks.py` (신규)

**Interfaces:**
- Consumes: `NotificationAttempt`(channel=webhook, recipient=endpoint id, payload=event dict, idempotency_key)
- Produces: `send_webhook(attempt, endpoint, timeout_sec) -> bool`, 서명 헤더 `X-KSI-Signature`(HMAC-SHA256 hex, secret+raw body) · `X-KSI-Delivery`(idempotency_key) · `X-KSI-Event`(event type) · `X-KSI-Timestamp`(unix sec, 리플레이 window 300s는 수신측 권고로 문서화만)
- Payload v1 JSON: `{version:"v1", event_id, idempotency_key, sent_at, type:"alert"|"test", event:{...}}`
- `WebhookEndpoint`: `id`(hex 16) · `name` · `url` · `secret` · `enabled` · `created_at` · `rotated_at`. `to_public_dict()`는 secret 마스킹(`"***"`, 생성·회전 직후 1회 평분기는 호출측 책임).
